# 桌游设计工作坊

一个**本地运行（localhost + 浏览器）**的桌游卡牌工作台，把「模板设计 → AI 生成底板 → 卡牌批量填值 → 导出印刷」串成一条流水线。

所有数据都存在你自己的磁盘上，不上传任何云端；AI 调用是可选的，不配 API Key 也能完整使用除 AI 生成以外的全部功能。

## 它解决什么问题

桌游的设计过程高度标准化，但现成工具都只覆盖其中一段：

| 工具类型 | 自由设计 | 表单填值 | 批量处理 | AI 生底板 | 本地离线 |
|---|---|---|---|---|---|
| 通用画布工具（如卡牌大师） | 有 | 无 | 无 | 部分 | 无 |
| 桌面批处理工具（如 CardEditor） | 无 | 无 | 有 | 无 | 有 |
| 单一卡种生成器（如游戏王生成器） | 无 | 有 | 无 | 无 | 无 |
| **本项目** | 有 | 有 | 有 | 有 | 有 |

核心思路是把**「模板里固定不变的东西」和「每张卡各不相同的东西」分开**：

- **模板**里放图层（卡框、底板、固定图标）+ 字段定义（卡名 / 费用 / 卡图 / 描述），每个字段标 `fixed`（锁定）或 `editable`（可按卡编辑）；
- **卡牌**只存这些字段的值。于是「画好一次模板 → 批量生成 200 张卡」成为同一条流水线，且所有文字都由本地渲染引擎绘制（不会出现 AI 把卡名写错字的情况）。

## 功能特性

### 项目管理

- 多项目并存，首页卡片墙展示封面、模板数、卡牌数、最近修改时间与标签
- 复制、重命名、删除项目
- **项目包导出 / 导入**（`.zip`，含 `manifest.json`；资源按 sha1 去重，跨机器导入后引用 100% 还原）
- **项目设定（ProjectBrief）**：游戏名、一句话卖点、简介、关键词、美术风格、主色板、派系、禁忌词 —— 它是所有 AI 调用的**唯一语料来源**，填得越细，生成结果越统一

### 模板编辑器

- Fabric.js 画布：拖拽 / 缩放 / 旋转，6 向对齐、吸附与参考线，方向键微调
- 图层树：拖拽排序、可见性、锁定
- 字段面板：字段类型（文本 / 多行文本 / 数字 / 枚举 / 图片 / 图标）、`fixed` 与 `editable`、约束（整数区间、枚举值）、样式（字号 / 字重 / 颜色 / 对齐 / 行高 / 字距 / 描边 / 自动缩放字号）
- **隐形定位框**：只在编辑器里显示的灰色虚线框，用于给 AI 底板流程标注区域位置，预览与导出完全不渲染
- 撤销重做（`Ctrl+Z` / `Ctrl+Shift+Z`），未保存离开时弹三选确认
- **含出血视图**：裁切框 + 2mm 安全框虚线，所见即所得
- **8 档卡牌尺寸预设**（以毫米为准，自动按 DPI 换算像素）：标准扑克 63×88 / 游戏王 59×86 / 桥牌 57×89 / 迷你卡 44×67 / 塔罗大卡 70×120 / 方形 70×70 / 超大卡 88×126 / 自定义
- 字体：内置族 + **本机已装字体扫描**（中英文别名双向搜索）+ 上传自定义字体（`ttf` / `otf`，注册后立即可用于画布，且随项目包迁移）

### 卡牌编辑

- 三栏布局：左 = 卡牌列表（搜索），中 = 实时预览，右 = 按模板字段动态生成的表单
- 两种填值模式：**表单模式**（单张精修）与**表格模式**（一行一卡、一列一字段，批量刷数值后一次性保存）
- 导入：JSON（直接按字段 key）/ CSV / 从 Excel 复制粘贴（自动识别制表符）
- **三步式字段映射对话框**：按表头自动匹配字段 key，可预览校验结果，再显式确认映射
- 图片字段支持**裁切**（比例默认取该字段区域的宽高比）与**从资源库选择**

### AI 生成（可选）

- **AI 生成底板**：在模板里画好区域框 → 服务端合成「布局参考图」→ 图生图（I2I）产出候选（1 / 2 / 4 张）→ 选中即应用为模板背景并锁定
- **AI 生成卡牌配图**：文生图（T2I），尺寸自动取该图片字段的区域大小，提示词自动带上卡名 / 描述 / 标签 / 派系与项目设定
- **后台生成 + 资源库挑选**：点「开始后台生成」立即关弹窗，完成后弹通知，再去资源库按生成时间挑图，不用在弹窗里干等 1~2 分钟
- **结果自动落盘 + 溯源**：拿到结果 URL 立刻下载到本地（远端 URL 仅 24 小时有效），并在 `assets.json` 记录 `aiProvenance`（模型 / 提示词 / 负向词 / seed / 尺寸 / 耗时）
- **提示词预览**：填写项目设定后可只读预览三个用途（底板 / 卡图 / 文案）拼出的完整提示词，不扣费

### 资源管理

- 内置 **6 个 icon 子库、43 个 SVG 图标**（元素 / 资源 / 状态 / 职业 / 箭头指示 / 数值骰子），统一 `currentColor` 描边，可换色
- 字体、图片、底板（AI 生成记录）四类资源的查看、上传、删除
- 缩略图自动生成（旧资源懒生成，无需迁移脚本）

### 统计

- 选定模板后，对每个数值 / 枚举字段渲染 ECharts 分布图（直方图 / 饼图）
- 离群值高亮告警（例如费用为 0 或超过常见区间）

### 导出

统一原则：**渲染全在浏览器完成**，前后端不会出现两套排版引擎导致的不一致。

| 层级 | 入口 | 产物 |
|---|---|---|
| **单张卡牌** | 卡牌编辑页「导出这张」 | PNG / JPG / 单页 PDF |
| **项目内批量** | 项目管理页批量操作条 | ZIP（逐张图，可选数据清单，可按模板分包）／ PDF 拼版 |
| **项目全部数据** | 项目卡片菜单 / 项目设置 | 项目包 `.zip`；纯数据 JSON / CSV |

- **两级出血模式**（二选一，产物尺寸不同，靠文件名 `_trim` / `_bleed` 后缀区分）：
  - `不含出血 trim`：净尺寸，如 745×1040 px = 63×88 mm，用于屏幕用图、规则书配图、TTS 导入
  - `含出血 bleed`：四周外扩 3 mm，如 817×1112 px = 69×94 mm，用于送印与裁切
- **PDF 拼版**：纸张 A4 / A3 / Letter，行列、页边距、卡间距可调；裁切角线始终画在净尺寸边界；含出血时可选**共享出血**（省纸）或**独立出血**（更好裁）；支持**背面对齐**（镜像 / 指定背面模板）
- 导出 DPI：150 / 300（默认）/ 600

## 快速开始

### 环境要求

| 依赖 | 版本 | 说明 |
|---|---|---|
| Python | 3.10 或更高 | 开发环境为 3.10.6 |
| Node.js | 18 或更高 | 开发环境为 20.16.0；仅构建前端时需要 |
| 浏览器 | Chrome / Edge 103+ 推荐 | 本机字体扫描依赖 `window.queryLocalFonts()`，其它浏览器会退化为预置字体探测 |

### 1. 安装 Python 依赖

```bash
python -m venv .venv

# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt
```

### 2. 构建前端

前端需要先构建成静态产物（`web/dist`），Python 服务端会把它托管起来：

```bash
cd web
npm install
npm run build
cd ..
```

> npm 安装慢的话可以换镜像：`npm install --registry=https://registry.npmmirror.com`

### 3. 启动

```bash
python run.py
```

浏览器会自动打开 <http://127.0.0.1:8770>，首次启动会自动创建一个「示例：法术卡」项目，照着它就能看懂整个流程。

### 可选：环境变量

| 变量 | 默认值 | 说明 |
|---|---|---|
| `BGW_PORT` | `8770` | 服务端口 |
| `BGW_HOST` | `127.0.0.1` | 仅本机访问；改成 `0.0.0.0` 可局域网访问（无鉴权，请勿在公网暴露） |
| `BGW_WORKSPACE` | `./workspace` | 数据目录，可以指向任意位置（如另一块盘） |
| `BGW_AUTO_OPEN` | `1` | 设为 `0` 则不自动打开浏览器 |

```bash
# Windows
set BGW_PORT=8780 && python run.py
# macOS / Linux
BGW_PORT=8780 python run.py
```

## 配置 AI 能力（可选）

在项目根目录新建 `.env` 文件：

```dotenv
# OpenLux 中转站（主通道，图像生成）
OPENLUX=sk-...

# 阿里云百炼 — 多模态（备选通道，走 DashScope 原生协议）
ALIYUN_MULTIMODAL=sk-...

# 阿里云百炼 — 文本（文生文能力尚未接入，可先留空）
ALIYUN_TEXT=sk-...
```

说明：

- `.env` **已在 `.gitignore` 中**，不会被提交；API Key 只在服务端进程内使用，任何接口响应都不会回传 Key。
- 三个 Key 全部留空 / 不创建 `.env` 时，除「AI 生成底板」与「AI 生成卡牌配图」之外的所有功能都正常工作。
- 图像生成默认模型为 `qwen-image-3.0-pro`（约 $0.00118 / 张），失败会自动重试；单次生成耗时参考：文生图 36~47 秒，图生图 75~172 秒，`n=4` 只比 `n=1` 多约 65%（并行生成）。
- 服务端启动后可用 `GET /api/ai/health` 与 `GET /api/ai/models` 检查通道连通性与可用模型。

## 第一次使用：5 分钟跑通一条流水线

1. **新建项目** —— 首页点「新建项目」，填写名称与标签。
2. **补项目设定** —— 进入项目概览页，左栏「项目设定」填游戏名、一句话卖点、关键词、美术风格与主色板。这一步直接影响 AI 生成质量，建议认真填。
3. **建模板** —— 「新建模板」选卡牌尺寸（8 档预设或自定义毫米尺寸 + DPI），进入模板编辑器。
4. **画版面** —— 在画布上加图层（卡框、底色）和字段（卡名、费用、卡图、描述），给每个字段设好位置、字号与约束。
5. **要底板（二选一）**
   - 「AI 生成底板」：点开后可先预览提示词并按需追加临时意图，选 1 / 2 / 4 张候选，转后台生成，完成后从资源库挑图应用；
   - 「本地上传」：直接传一张自己做的底图（建议按含出血尺寸裁剪，渲染器会 1:1 对齐而不缩放）。
6. **批量填卡** —— 卡牌页可逐张精修，也可以切**表格模式**一行一卡批量刷数值，或导入 CSV / 从 Excel 粘贴后在字段映射对话框里对齐列。
7. **看统计** —— 项目概览页的数值分布图检查是否有离群值（如费用为 0 或超出预期区间）。
8. **导出** —— 屏幕用图选 `trim`，送印选 `bleed`；批量走 ZIP 或 PDF 拼版。

## 数据存放与备份

所有数据都在 `workspace/` 目录（可用 `BGW_WORKSPACE` 改到别处）：

```
workspace/
├─ projects/<pid>/
│  ├─ project.json              # 项目信息 + 创作简报
│  ├─ project.json.bak          # 写入前自动快照
│  ├─ templates/<tid>/
│  │  ├─ template.json          # 模板：图层 + 字段
│  │  ├─ base.png               # 底板
│  │  └─ preview.png            # 预览图
│  ├─ cards/<cid>.json          # 一张卡一个文件
│  ├─ cards/_index.json         # 卡牌索引
│  └─ exports/                  # 导出产物（不入库）
├─ assets/
│  ├─ icons/<子库>/             # 内置图标（首次启动自动生成）
│  ├─ fonts/  images/  baseplates/
│  ├─ thumbs/                   # 缩略图
│  └─ assets.json               # 资源清单，含 AI 溯源信息
└─ jobs/                        # AI 任务状态（落盘，进程重启可恢复）
```

- **备份**：整个 `workspace/` 目录拷走即可；或在界面上导出项目包 `.zip`（更适合分享给别人）。
- **迁移到另一台机器**：项目包会带上「实际引用到的」资源子集与 `manifest.json`，导入时按 sha1 去重。
- **注意**：模板里用到的**本机字体不会复制文件**。如果要把项目发给别人，请把字体上传为自定义字体（资源页 → 字体 → 上传），这样才会随项目包一起走。

## 常见问题

**打开页面显示 `{"error": "前端未构建，请先执行：cd web && npm install && npm run build"}`**

前端产物不存在。按提示构建一次即可，之后 `python run.py` 就能正常打开。

**点了 AI 生成但报错 / 一直失败**

检查根目录 `.env` 里的 Key 是否有效。可以先访问 `http://127.0.0.1:8770/api/ai/health` 看通道状态，或跑一遍上面的探针脚本。注意图像结果 URL 只有 24 小时有效期，本项目已自动下载落盘，不需要你手动保存。

**AI 生成要等很久**

正常现象：文生图约 36~47 秒/张，图生图约 75~172 秒/张。所以底板与卡图都设计成「转后台生成 + 完成后通知」，不用守着弹窗。`n=4` 是并行生成，只比 `n=1` 多约 65%。

**在别人的电脑上打开，字体变成默认字体了**

本机字体只记录族名、不复制文件，对方没装就会回退。需要跨机器一致请上传为自定义字体。

**批量导出很慢 / 卡住**

批量导出在浏览器内存里完成。超过 200 张会自动分批并逐张释放，建议同时把 DPI 降到 150。

**端口被占用**

用 `BGW_PORT` 换一个，例如 `set BGW_PORT=8780 && python run.py`。

**能不能局域网访问 / 手机上看**

可以设 `BGW_HOST=0.0.0.0` 让局域网其他设备访问，但**没有任何鉴权**，请不要在公网环境这样用。移动端触屏适配未做。

**清空项目设定时提示 409 错误**

这是防误清空保护：当服务器上已有内容而提交的是空值时，需要显式确认。前端会弹二次确认后再提交。
